# Miraheze Wiki Setup Draft

## Recommended scope

Create one public, English-language community wiki for New Super Mario Bros. U Deluxe modding. Keep the general modding guides, tool documentation, community research, and Steam's New Super Mario Bros. Deluxe project together so contributors and readers have one place to start.

## Request details to confirm

- **Proposed title:** New Super Mario Bros. U Deluxe Modding Wiki
- **Preferred subdomain:** `nsmbudx` (check availability and existing wikis before requesting; this is a preference, not a reserved address)
- **Language:** English
- **Visibility:** Public
- **Hosting:** Miraheze

### Draft request description

This wiki will be a community-maintained knowledge base for modding New Super Mario Bros. U Deluxe. It will document community tools such as the Yaz0moto level editor and SweetDX custom-code compiler, publish beginner-friendly setup and creation guides, and collect researched information about the game's behavior and mod-development techniques. It will also document Steam's New Super Mario Bros. Deluxe, a community mod project, while clearly separating project-specific information from general game-modding resources. The wiki is intended to help players, creators, testers, and researchers learn from one another and contribute accurate, useful documentation. It will not host game copies, copyrighted game files, or instructions to obtain them; readers must provide their own legally obtained game copy where needed.

## Suggested first pages

1. **Main Page** — explain the wiki's scope and point readers to tools, beginner guides, research, and the featured mod.
2. **Getting Started with Modding** — prerequisites, safe setup principles, and links to maintained tool documentation.
3. **Yaz0moto** — level-editor overview, installation notes, supported workflows, and community tips.
4. **SweetDX** — compiler overview, requirements, setup, and links to its source documentation.
5. **Steam's New Super Mario Bros. Deluxe** — project overview, current public status, and official project links.
6. **Level Design** — community techniques and examples, with attribution for creator-submitted work.
7. **Game Research** — sourced findings about game behavior, clearly marked as confirmed, under investigation, or speculative.
8. **Contributing** — how to improve articles, submit corrections, and document sources.
9. **Community and Legal Notice** — unofficial status, ownership of Nintendo materials, and the rule against uploading game files.

## Editorial principles

- Keep general modding documentation separate from claims about the featured mod.
- Link to upstream repositories and their own requirements instead of copying tool releases or game data.
- Cite public sources and label unverified findings clearly.
- Publish original guides and community-created examples with clear attribution and permission.
- Do not upload game files, game executables, or Nintendo-owned assets to the wiki.
- Review Miraheze's current Content Policy and Dormancy Policy before submitting and while maintaining the wiki.

## Launch checklist

- Sign in to Miraheze; anonymous users cannot submit a new-wiki request.
- Search Miraheze's existing wikis for NSMBU Deluxe modding topics to avoid an unnecessary duplicate.
- Confirm the final title, scope, and preferred subdomain with the project maintainers.
- Submit the request through [Miraheze's Request a Wiki page](https://meta.miraheze.org/wiki/Special:RequestWiki) and agree to the policies shown there.
- After approval, create the Main Page and starter pages, then replace the website's request-page link with the approved wiki URL.
